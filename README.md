# El conde Lucanor · 15 exemplos

App de repaso autocorregible de 15 cuentos de *El conde Lucanor* (don Juan Manuel): I, II, V, VI, VII, X, XI, XXIV, XXVI, XXXII, XXXIV, XXXV, XXXVIII, XLII y XLVIII.

- **Fichas** de cada cuento: problema del conde, resumen, personajes, consejo de Patronio, moraleja, enseñanza, aplicación actual y avisos para el examen.
- **Ejercicios autocorregibles** con explicación de cada error: elegir, verdadero/falso, completar versos, ordenar la historia, relacionar moralejas y situaciones actuales.
- **Respuestas escritas** (resúmenes, enseñanzas y reflexiones) corregidas por ideas clave, con respuesta modelo.
- **Repaso de fallos** y **simulacro de examen** con nota sobre 10.

Es un único archivo (`index.html`), sin instalación. El progreso de cada alumno se guarda solo en su navegador.

## Cómo compartirla con los alumnos

Activa GitHub Pages en *Settings → Pages → Branch: `main` / root* y comparte la dirección:

https://nuriacalvo-teacher.github.io/conde-lucanor/
